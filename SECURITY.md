# Security Policy

## Scope

This repository is a public, sanitized description of a private personal environment. It does not contain the live deployment, production configuration, credentials, private network details, service databases, personal media, Home Assistant entities, or backup contents.

## Reporting a concern

If you believe a file in this repository reveals sensitive information, please do not post the details in a public issue. Use GitHub's private vulnerability reporting feature if it is available. If it is not available, open a minimal issue that requests a private contact channel without describing the sensitive detail.

## Supported material

The documentation and synthetic examples on the default branch are the only supported public materials. The private Nova environment is not a public service or open-source deployment.

## Safety principles

- No secrets or private environment values belong in this repository.
- Examples must use placeholders and synthetic identifiers.
- Architecture diagrams must remain high level.
- AI capabilities must be labeled by verified status.
- Suspected exposure should be removed from publication and reviewed before republishing.
